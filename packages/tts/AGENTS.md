# dsh-whale-tts 使用手册（给 AI）

> 人类读者看 [README.md](README.md)。

## 你面对的是什么

`whale_speak` 用本地 GPT-SoVITS 模型把文字变成语音。插件会自己拉起一个 Python 推理服务，你不需要手动启动。

首次使用前，确认设置页（设置 → 「GPT-SoVITS 语音」）已经填好 Python 路径、模型、参考音频和参考文本；否则第一次调用会报 `pythonPath / gsvRoot 未配置`。第一次调用还要等模型加载，可能几十秒。

## 什么时候调用

- 你想「说话」，把一句文本变成声音。
- 你想给视频或其他作品配音，需要一段音频文件。
- 用户明确要你念某段文字。

不要用它做：

- 长篇文章朗读（单次调用会一次性生成，太长会慢）。
- 实时流式对话（没有流式接口）。

## 参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `text` | 是 | 要说的文本 |
| `play` | 否 | `true` = 直接播放 |
| `keep_dir` | 否 | 保存目录；不播放时必填 |
| `speed` | 否 | 语速，默认 `1.0`，一般不用改 |

## 选哪种模式

| 你的目的 | 怎么调 |
|---|---|
| 只想让用户听到，不留文件 | `play: true`，不传 `keep_dir` |
| 只想留文件，先不播放 | `play: false`，传 `keep_dir` |
| 既播放又留文件 | `play: true`，传 `keep_dir` |
| 想给视频配音 | `play: false`，`keep_dir` 指向作品目录 |

## 返回

```json
{
  "ok": true,
  "file": "保留路径或缓存路径",
  "cache_file": "仅在播放或未保留时出现",
  "played": true,
  "kept": true,
  "bytes": 123456
}
```

- `file` 是你后续要用的路径：要保留时就是保留路径，否则是缓存路径。
- `cache_file` 只在「播放」或「未保留」时出现。
- 想引用音频给用户看，用返回的 `file`。

## 缓存

所有音频都会先写进插件的 `cache/`。缓存由设置页的「清理缓存」管理，不要自己删。

## 出错时

| 错误 | 意思 | 怎么办 |
|---|---|---|
| `pythonPath / gsvRoot 未配置` | 设置页缺路径 | 告诉用户去设置页填 |
| `TTS 服务启动超时` | Python 或模型有问题 | 让用户检查 Python 能否 import torch |
| `TTS 失败（500）：...` | 推理报错 | 把错误原文告诉用户 |
| `不播放时必须提供 keep_dir` | 参数组合不完整 | 补 `keep_dir` 或改 `play: true` |

## 不要做

- 不要为了「播放」而传 `keep_dir` 又不告诉用户文件在哪。
- 不要假设音频已经播放成功——`played` 只表示插件发起了播放。
- 不要在没有 `keep_dir` 时把缓存路径当成永久文件交给用户。
